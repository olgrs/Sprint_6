# Sprint_6 — UI-автотесты для сервиса «Яндекс.Самокат»

Проект с автотестами на Python + Selenium (Firefox) с использованием Page Object Model и Allure для проверки функциональности сервиса «Яндекс.Самокат» (https://qa-scooter.education-services.ru/).
Разработан в рамках курса Яндекс Практикума, спринт «UI-тестирование».

## Тестовые сценарии

Покрыты следующие функциональности:

- **Блок «Вопросы о важном»**  
  Проверка ответа на каждый из 8 вопросов: при клике на вопрос открывается соответствующий текст.
- **Заказ самоката (позитивный сценарий)**  
  Проверка полного флоу заказа через две разные точки входа (верхняя и нижняя кнопки «Заказать») с двумя наборами данных.  
  Валидация появления окна «Заказ оформлен».  
  Проверка возврата на главную при клике на логотип «Самоката».  
  Проверка перехода на главную страницу Дзена при клике на логотип Яндекса (новая вкладка, редирект).

## Запуск тестов

1. Установите зависимости:
    pip install -r requirements.txt
2. Убедитесь, что установлен браузер Mozilla Firefox.
3. Запустите все тесты с сохранением данных для Allure:
    pytest tests/ --alluredir=allure-results
4. Просмотрите отчёт локально:
    allure serve allure-results

## Требования

- Python 3.9+
- Mozilla Firefox
- Пакеты: selenium, pytest, allure-pytest
- Allure Command Line (для генерации отчёта)
